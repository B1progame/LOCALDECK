# Help

| Question | Where |
|---|---|
| How does something work? | [README](README.md) and the [documents](docs) |
| Something is broken | [Report a bug](https://github.com/B1progame/LOCALDECK/issues/new/choose) |
| I have an idea | [Suggest it](https://github.com/B1progame/LOCALDECK/issues/new/choose) |
| A security problem | [Privately](.github/SECURITY.md), not as an issue |
| My data and my account | The address on the [privacy page](https://b1progame.github.io/LOCALDECK/#/privacy). Accounts can be deleted under **Shared links** |

LocalDeck is made in free time, so an answer may take a few days.
